# Milestone 1 — Look Test Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn a hand-written 2-line `performance.json` into a roughly 6-second, 9:16, lip-synced, mood-shifting, color-graded and captioned clip, to check the visual quality bar before anything else is built.

**Architecture:** A Python package called `reelforge`, using only the standard library, runs the pipeline stages:
- voice: ElevenLabs
- timeline
- face tracks: lip-sync shapes, emotion and blinks
- shot list and color moods
- captions (an `.ass` subtitle file)
- render plan

It then hands off a single `render_plan.json` file to Blender, run without a window. Blender renders PNG frames, and ffmpeg adds the finishing look, captions and audio loudness.

Blender scripts only use Python's standard library plus `reelforge.arkit`. Characters expose 52 standard ARKit face controls as custom properties on a `FaceCtrl` object. Inside the character file, simple drivers link those controls to the actual face geometry. This means a professionally made head can later replace the procedural one without touching the pipeline.

**Tech Stack:**
- Python 3.12+ (system 3.14) and pytest
- Blender 4.5 LTS, using the Eevee Next renderer with ray tracing
- ffmpeg 9 with its loudnorm, ass, vignette and noise filters
- ElevenLabs v3 `with-timestamps` API

**Spec:** `docs/superpowers/specs/2026-10-31-animated-reel-generator-design.md`, Milestone 1.

## Global Constraints

- The default aspect ratio is 9:16 at 1080×1920. All four ratios must be accepted by the schema: `9:16`, `16:9`, `3:4`, `1:1`.
- fps is one of 24, 25, 30 or 60; the default is 30.
- Face channels use the exact ARKit 52 blendshape names. The characters' left side is ARKit `...Left`, which is +X in Blender because the characters face −Y.
- ElevenLabs model is `eleven_v3`. The endpoint is `POST https://api.elevenlabs.io/v1/text-to-speech/{voice_id}/with-timestamps?output_format=mp3_44100_128`. The API key comes from the `ELEVENLABS_API_KEY` environment variable and is never written to disk.
- Instagram 9:16 safe zone: the top 220 px and bottom 420 px must stay clear of captions.
- Final loudness is −14 LUFS integrated, with a true peak of −1.5 dB. Video is H.264 (crf 16, yuv420p) and audio is AAC at 192k.
- Each stage caches its outputs. Re-running a stage with unchanged inputs must not call ElevenLabs again.
- The `reelforge/` package uses no third-party runtime dependencies. pytest is dev-only.
- Blender is version 4.5 LTS, found through the `REELFORGE_BLENDER` environment variable.

**Out of scope for Milestone 1 (planned for Milestone 2):** the Claude performance pass, a second on-screen character, listener reactions, moving captions to avoid faces, and the music and foley beds. Audio2Face is a time-boxed spike (Task 14). If it can't be made to work, Milestone 1 ships with the timestamp-based lip-sync shapes.

```python
from __future__ import annotations

import json
from dataclasses import dataclass
from pathlib import Path

EMOTIONS = ("neutral", "happy", "sad", "worried", "surprised", "smug", "deadpan",
            "confused", "annoyed", "thinking", "embarrassed")
MOODS = ("calm", "success", "panic", "awkward", "reveal", "sad")
RATIOS: dict[str, tuple[int, int]] = {
    "9:16": (1080, 1920), "16:9": (1920, 1080), "3:4": (1080, 1440), "1:1": (1080, 1080),
}
REQUIRED_LINE_KEYS = ("id", "speaker", "text", "emotion", "intensity", "mood")


class PerformanceError(ValueError):
    pass


@dataclass(frozen=True)
class Character:
    name: str
    voice_id: str
    caption_color: str
    highlight_color: str


@dataclass(frozen=True)
class Line:
    id: str
    speaker: str
    text: str
    emotion: str
    intensity: float
    mood: str
    pause_after: float = 0.3
    punchline: bool = False


@dataclass(frozen=True)
class Performance:
    fps: int
    ratio: str
    environment: str
    characters: dict[str, Character]
    lines: list[Line]


def load_performance(path: Path) -> Performance:
    return parse_performance(json.loads(Path(path).read_text(encoding="utf-8")))


def parse_performance(data: dict) -> Performance:
    errors: list[str] = []
    fps = data.get("fps", 30)
    if fps not in (24, 25, 30, 60):
        errors.append(f"fps must be 24/25/30/60, got {fps}")
    ratio = data.get("ratio", "9:16")
    if ratio not in RATIOS:
        errors.append(f"ratio must be one of {list(RATIOS)}, got {ratio}")

    chars: dict[str, Character] = {}
    for name, c in (data.get("characters") or {}).items():
        if "voice_id" not in c:
            errors.append(f"character {name}: missing voice_id")
            continue
        chars[name] = Character(name, c["voice_id"], c.get("caption_color", "#FFFFFF"),
                                c.get("highlight_color", "#FFD23F"))
    if not chars:
        errors.append("at least one character required")

    lines: list[Line] = []
    seen: set[str] = set()
    for i, raw in enumerate(data.get("lines") or []):
        where = f"lines[{i}]"
        missing = [k for k in REQUIRED_LINE_KEYS if k not in raw]
        if missing:
            errors.append(f"{where}: missing {missing}")
            continue
        if raw["id"] in seen:
            errors.append(f"{where}: duplicate id {raw['id']}")
        seen.add(raw["id"])
        if raw["speaker"] not in chars:
            errors.append(f"{where}: unknown speaker {raw['speaker']}")
        if raw["emotion"] not in EMOTIONS:
            errors.append(f"{where}: emotion must be one of {EMOTIONS}")
        if raw["mood"] not in MOODS:
            errors.append(f"{where}: mood must be one of {MOODS}")
        intensity = float(raw["intensity"])
        if not 0.0 <= intensity <= 1.0:
            errors.append(f"{where}: intensity must be 0..1")
        lines.append(Line(raw["id"], raw["speaker"], raw["text"], raw["emotion"], intensity,
                          raw["mood"], float(raw.get("pause_after", 0.3)),
                          bool(raw.get("punchline", False))))
    if not lines:
        errors.append("at least one line required")
    if errors:
        raise PerformanceError("; ".join(errors))
    return Performance(fps, ratio, data.get("environment", "night_city"), chars, lines)
```

```python
from __future__ import annotations

from dataclasses import dataclass


@dataclass(frozen=True)
class Char:
    ch: str
    start: float
    end: float


@dataclass(frozen=True)
class Word:
    text: str
    start: float
    end: float


def clean_chars(chars: list[str], starts: list[float], ends: list[float]) -> list[Char]:
    """Drop ElevenLabs audio tags like "[sighs]" (they're in the text, not spoken)."""
    out: list[Char] = []
    depth = 0
    for ch, s, e in zip(chars, starts, ends):
        if ch == "[":
            depth += 1
            continue
        if ch == "]":
            depth = max(0, depth - 1)
            continue
        if depth == 0:
            out.append(Char(ch, float(s), float(e)))
    while out and out[0].ch.isspace():
        out.pop(0)
    return out


def words_from_chars(chars: list[Char]) -> list[Word]:
    words: list[Word] = []
    cur: list[Char] = []
    for c in [*chars, Char(" ", 0.0, 0.0)]:
        if c.ch.isspace():
            if cur:
                words.append(Word("".join(x.ch for x in cur), cur[0].start, cur[-1].end))
                cur = []
        else:
            cur.append(c)
    return words
```

```python
from __future__ import annotations

import base64
import hashlib
import json
import time
import urllib.error
import urllib.request
from dataclasses import dataclass
from pathlib import Path

from .alignment import Char, clean_chars
from .schema import Line

MODEL = "eleven_v3"
URL = ("https://api.elevenlabs.io/v1/text-to-speech/{voice_id}/with-timestamps"
       "?output_format=mp3_44100_128")
RETRY_CODES = {429, 500, 502, 503, 504}


class VoiceError(RuntimeError):
    pass


@dataclass(frozen=True)
class VoicedLine:
    line_id: str
    audio_path: Path
    chars: list[Char]


def _http_post(url: str, headers: dict, body: dict) -> dict:
    req = urllib.request.Request(url, data=json.dumps(body).encode("utf-8"),
                                 headers=headers, method="POST")
    with urllib.request.urlopen(req, timeout=180) as r:
        return json.loads(r.read())


def _cache_key(text: str, voice_id: str) -> str:
    return hashlib.sha1(f"{MODEL}|{voice_id}|{text}".encode("utf-8")).hexdigest()[:10]


def synthesize_line(line: Line, voice_id: str, out_dir: Path, api_key: str,
                    post=_http_post, retries: int = 3, sleep=time.sleep) -> VoicedLine:
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    mp3 = out_dir / f"{line.id}-{_cache_key(line.text, voice_id)}.mp3"
    meta = mp3.with_suffix(".json")
    if not (mp3.exists() and meta.exists()):
        url = URL.format(voice_id=voice_id)
        headers = {"xi-api-key": api_key, "Content-Type": "application/json"}
        body = {"text": line.text, "model_id": MODEL}
        resp = None
        for attempt in range(retries):
            try:
                resp = post(url, headers, body)
                break
            except urllib.error.HTTPError as e:
                if e.code in RETRY_CODES and attempt < retries - 1:
                    sleep(2 ** attempt)
                    continue
                raise VoiceError(f"ElevenLabs failed for {line.id}: HTTP {e.code}") from e
            except urllib.error.URLError as e:
                if attempt < retries - 1:
                    sleep(2 ** attempt)
                    continue
                raise VoiceError(f"ElevenLabs unreachable for {line.id}: {e.reason}") from e
        mp3.write_bytes(base64.b64decode(resp["audio_base64"]))
        meta.write_text(json.dumps(resp["alignment"]), encoding="utf-8")
    a = json.loads(meta.read_text(encoding="utf-8"))
    chars = clean_chars(a["characters"], a["character_start_times_seconds"],
                        a["character_end_times_seconds"])
    return VoicedLine(line.id, mp3, chars)
```

```python
from __future__ import annotations

import subprocess
from dataclasses import dataclass
from pathlib import Path

from .schema import Line
from .voice import VoicedLine

LEAD_IN = 0.4
TAIL = 0.8


@dataclass(frozen=True)
class Placed:
    line: Line
    voiced: VoicedLine
    start: float
    duration: float


def probe_duration(path) -> float:
    r = subprocess.run(["ffprobe", "-v", "error", "-show_entries", "format=duration",
                        "-of", "csv=p=0", str(path)], capture_output=True, text=True, check=True)
    return float(r.stdout.strip())


def place_lines(lines: list[Line], voiced: dict[str, VoicedLine],
                durations: dict[str, float]) -> tuple[list[Placed], float]:
    t = LEAD_IN
    placed: list[Placed] = []
    for line in lines:
        d = durations[line.id]
        placed.append(Placed(line, voiced[line.id], t, d))
        t += d + line.pause_after
    return placed, t + TAIL


def mix_dialogue(placed: list[Placed], total: float, out_wav: Path) -> Path:
    cmd = ["ffmpeg", "-y", "-loglevel", "error"]
    for p in placed:
        cmd += ["-i", str(p.voiced.audio_path)]
    parts = []
    for i, p in enumerate(placed):
        ms = int(round(p.start * 1000))
        parts.append(f"[{i}:a]aresample=48000,aformat=channel_layouts=mono,"
                     f"adelay={ms}:all=1[a{i}]")
    ins = "".join(f"[a{i}]" for i in range(len(placed)))
    parts.append(f"{ins}amix=inputs={len(placed)}:normalize=0:duration=longest,"
                 f"apad=whole_dur={total:.3f}[out]")
    cmd += ["-filter_complex", ";".join(parts), "-map", "[out]", "-t", f"{total:.3f}",
            "-ar", "48000", str(out_wav)]
    subprocess.run(cmd, check=True)
    return Path(out_wav)
```

```python
"""Grapheme-based visemes from ElevenLabs char timings. Fallback when Audio2Face is unavailable."""
from __future__ import annotations

from .alignment import Char

VISEME_POSES: dict[str, dict[str, float]] = {
    "sil": {},
    "AA": {"jawOpen": 0.55, "mouthFunnel": 0.1},
    "EE": {"jawOpen": 0.25, "mouthStretchLeft": 0.35, "mouthStretchRight": 0.35},
    "OH": {"jawOpen": 0.4, "mouthFunnel": 0.6},
    "OO": {"jawOpen": 0.12, "mouthPucker": 0.85},
    "MBP": {"mouthClose": 0.7, "mouthPressLeft": 0.4, "mouthPressRight": 0.4},
    "FV": {"jawOpen": 0.08, "mouthRollLower": 0.6},
    "TH": {"jawOpen": 0.2, "tongueOut": 0.3},
    "LNT": {"jawOpen": 0.22},
    "SZ": {"jawOpen": 0.08, "mouthStretchLeft": 0.25, "mouthStretchRight": 0.25},
    "CH": {"jawOpen": 0.15, "mouthFunnel": 0.35},
    "KG": {"jawOpen": 0.3},
    "R": {"jawOpen": 0.18, "mouthFunnel": 0.3},
}
VOWELS = {"AA", "EE", "OH", "OO"}
FULL_STRENGTH = {"MBP", "FV"}  # lip closures must hit fully or sync looks wrong
CONSONANT_SCALE = 0.75
GAP_SIL = 0.15

DIGRAPHS = {"th": "TH", "ch": "CH", "sh": "CH", "oo": "OO", "ee": "EE", "ph": "FV",
            "ck": "KG", "qu": "KG", "ou": "OH", "ow": "OH"}
LETTERS = {"a": "AA", "e": "EE", "i": "EE", "y": "EE", "o": "OH", "u": "OO", "w": "OO",
           "b": "MBP", "m": "MBP", "p": "MBP", "f": "FV", "v": "FV",
           "l": "LNT", "n": "LNT", "t": "LNT", "d": "LNT",
           "s": "SZ", "z": "SZ", "c": "SZ", "x": "SZ", "j": "CH",
           "k": "KG", "g": "KG", "q": "KG", "r": "R"}  # 'h' intentionally silent


def viseme_events(chars: list[Char]) -> list[tuple[float, str]]:
    events: list[tuple[float, str]] = []
    prev_end: float | None = None
    i, n = 0, len(chars)
    while i < n:
        c = chars[i]
        low = c.ch.lower()
        if not low.isalpha():
            i += 1
            continue
        if prev_end is not None and c.start - prev_end > GAP_SIL:
            events.append((prev_end + 0.06, "sil"))
            events.append((c.start - 0.06, "sil"))
        pair = low + chars[i + 1].ch.lower() if i + 1 < n else ""
        if pair in DIGRAPHS:
            v, s, e = DIGRAPHS[pair], c.start, chars[i + 1].end
            i += 2
        else:
            v, s, e = LETTERS.get(low), c.start, c.end
            i += 1
        prev_end = e
        if v:
            events.append(((s + e) / 2, v))
    if events:
        events.insert(0, (max(0.0, events[0][0] - 0.12), "sil"))
        events.append((prev_end + 0.08, "sil"))
    return events


def _pose(v: str) -> dict[str, float]:
    base = VISEME_POSES[v]
    if v in VOWELS or v in FULL_STRENGTH:
        return base
    return {k: x * CONSONANT_SCALE for k, x in base.items()}


def _smooth(x: float) -> float:
    return x * x * (3 - 2 * x)


def sample_tracks(events: list[tuple[float, str]], fps: int, n_frames: int) -> dict[str, list[float]]:
    channels = sorted({k for _, v in events for k in VISEME_POSES[v]})
    tracks = {c: [0.0] * n_frames for c in channels}
    if len(events) < 2:
        return tracks
    j = 0
    for f in range(n_frames):
        t = f / fps
        if t <= events[0][0] or t >= events[-1][0]:
            continue
        while j + 1 < len(events) and events[j + 1][0] <= t:
            j += 1
        t0, v0 = events[j]
        t1, v1 = events[j + 1]
        a = _smooth((t - t0) / (t1 - t0)) if t1 > t0 else 1.0
        p0, p1 = _pose(v0), _pose(v1)
        for c in channels:
            tracks[c][f] = p0.get(c, 0.0) * (1 - a) + p1.get(c, 0.0) * a
    return tracks
```

```python
from __future__ import annotations

import math
import random

from .alignment import words_from_chars
from .arkit import ARKIT_NAMES
from .schema import Performance
from .timeline import Placed
from .visemes import sample_tracks, viseme_events

ANTICIPATION = 0.15  # emotion starts slightly before the line
NERVOUS = {"worried", "embarrassed"}
BLINK_SHAPE = (0.5, 1.0, 1.0, 0.6, 0.2)

EMOTION_POSES: dict[str, dict[str, float]] = {
    "neutral": {},
    "happy": {"mouthSmileLeft": 0.6, "mouthSmileRight": 0.6, "cheekSquintLeft": 0.35,
              "cheekSquintRight": 0.35, "browInnerUp": 0.1},
    "sad": {"browInnerUp": 0.7, "mouthFrownLeft": 0.5, "mouthFrownRight": 0.5,
            "eyeSquintLeft": 0.1, "eyeSquintRight": 0.1},
    "worried": {"browInnerUp": 0.6, "mouthStretchLeft": 0.2, "mouthStretchRight": 0.2,
                "mouthFrownLeft": 0.2, "mouthFrownRight": 0.2},
    "surprised": {"browOuterUpLeft": 0.8, "browOuterUpRight": 0.8, "browInnerUp": 0.6,
                  "eyeWideLeft": 0.7, "eyeWideRight": 0.7, "jawOpen": 0.15},
    "smug": {"mouthSmileLeft": 0.55, "mouthSmileRight": 0.1, "browDownRight": 0.3,
             "eyeSquintLeft": 0.3, "eyeSquintRight": 0.3},
    "deadpan": {"eyeBlinkLeft": 0.35, "eyeBlinkRight": 0.35, "mouthPressLeft": 0.2,
                "mouthPressRight": 0.2},
    "confused": {"browDownLeft": 0.5, "browOuterUpRight": 0.6, "mouthLeft": 0.3},
    "annoyed": {"browDownLeft": 0.6, "browDownRight": 0.6, "mouthPressLeft": 0.4,
                "mouthPressRight": 0.4, "noseSneerLeft": 0.2, "noseSneerRight": 0.2},
    "thinking": {"browDownLeft": 0.3, "browInnerUp": 0.3, "mouthRight": 0.3,
                 "eyeLookUpLeft": 0.4, "eyeLookUpRight": 0.4},
    "embarrassed": {"mouthSmileLeft": 0.3, "mouthSmileRight": 0.3, "browInnerUp": 0.4,
                    "eyeLookDownLeft": 0.5, "eyeLookDownRight": 0.5},
}


def spring(values: list[float], fps: int, k: float = 180.0, c: float = 16.0) -> list[float]:
    """Damped spring follower (damping ratio ~0.6): gives anticipation-free overshoot + settle."""
    if not values:
        return []
    x, v, dt = values[0], 0.0, 1.0 / fps
    out = []
    for target in values:
        v += ((target - x) * k - v * c) * dt
        x += v * dt
        out.append(x)
    return out


def emotion_targets(placed: list[Placed], fps: int, n_frames: int) -> dict[str, list[float]]:
    t: dict[str, list[float]] = {}
    for i, p in enumerate(placed):
        a = max(0, int(round((p.start - ANTICIPATION) * fps)))
        b = n_frames if i == len(placed) - 1 else max(a, int(round((placed[i + 1].start - ANTICIPATION) * fps)))
        for ch, val in EMOTION_POSES[p.line.emotion].items():
            arr = t.setdefault(ch, [0.0] * n_frames)
            for f in range(a, min(b, n_frames)):
                arr[f] = val * p.line.intensity
    return t


def _emotion_at(placed: list[Placed], t: float) -> str:
    current = "neutral"
    for p in placed:
        if p.start - ANTICIPATION <= t:
            current = p.line.emotion
    return current


def blink_track(placed: list[Placed], fps: int, n_frames: int, seed: int = 7) -> list[float]:
    rng = random.Random(seed)
    out = [0.0] * n_frames
    t = rng.uniform(0.8, 2.0)
    while t * fps < n_frames:
        f = int(t * fps)
        for k, val in enumerate(BLINK_SHAPE):
            if f + k < n_frames:
                out[f + k] = max(out[f + k], val)
        nervous = _emotion_at(placed, t) in NERVOUS
        t += rng.uniform(1.5, 3.0) if nervous else rng.uniform(2.5, 5.0)
    return out


def nod_track(placed: list[Placed], fps: int, n_frames: int) -> list[float]:
    """Small head dips on the longest (≈stressed) words; scaled by intensity."""
    out = [0.0] * n_frames
    for p in placed:
        words = words_from_chars(p.voiced.chars)
        if not words:
            continue
        stressed = sorted(words, key=lambda w: w.end - w.start, reverse=True)[:max(1, len(words) // 4)]
        amp = 0.05 + 0.08 * p.line.intensity
        for w in stressed:
            f0 = int(round((p.start + w.start) * fps))
            for k in range(8):
                if 0 <= f0 + k < n_frames:
                    out[f0 + k] += amp * math.sin(math.pi * k / 8)
    return out


def build_faces(perf: Performance, placed: list[Placed], fps: int, n_frames: int,
                lipsync_override: dict[str, dict[str, list[float]]] | None = None
                ) -> dict[str, dict[str, list[float]]]:
    override = lipsync_override or {}
    faces: dict[str, dict[str, list[float]]] = {}
    for name in perf.characters:
        mine = [p for p in placed if p.line.speaker == name]
        tracks = {c: [0.0] * n_frames for c in ARKIT_NAMES}
        for ch, vals in emotion_targets(mine, fps, n_frames).items():
            tracks[ch] = spring(vals, fps)
        for p in mine:
            local = override.get(p.line.id)
            if local is None:
                n_local = int(math.ceil(p.duration * fps)) + 2
                local = sample_tracks(viseme_events(p.voiced.chars), fps, n_local)
            off = int(round(p.start * fps))
            for ch, vals in local.items():
                if ch not in tracks:
                    continue
                for k, v in enumerate(vals):
                    if 0 <= off + k < n_frames:
                        tracks[ch][off + k] += v
        blink = blink_track(mine, fps, n_frames, seed=sum(map(ord, name)))
        for side in ("eyeBlinkLeft", "eyeBlinkRight"):
            tracks[side] = [max(a, b) for a, b in zip(tracks[side], blink)]
        for ch in ARKIT_NAMES:
            tracks[ch] = [min(1.0, max(0.0, v)) for v in tracks[ch]]
        tracks["headNod"] = nod_track(mine, fps, n_frames)
        faces[name] = tracks
    return faces
```

```python
from __future__ import annotations

import math
from dataclasses import dataclass, replace

from .timeline import Placed

LENSES = {"wide": 35, "medium": 50, "closeup": 85}
MAX_SHOT_S = 3.0
CUT_LEAD_FRAMES = 4  # cut slightly before the line starts
MOOD_LEAD_S = 0.15


@dataclass(frozen=True)
class Shot:
    start_frame: int
    end_frame: int  # exclusive
    kind: str
    lens: float
    subject: str
    push: float


def plan_shots(placed: list[Placed], fps: int, n_frames: int) -> list[Shot]:
    shots: list[Shot] = []
    for i, p in enumerate(placed):
        start = 0 if i == 0 else max(0, int(round(p.start * fps)) - CUT_LEAD_FRAMES)
        end = n_frames if i == len(placed) - 1 else int(round(placed[i + 1].start * fps)) - CUT_LEAD_FRAMES
        close = p.line.punchline or p.line.intensity >= 0.7
        kind = "closeup" if close else ("wide" if i == 0 else "medium")
        push = 0.12 if kind == "wide" or p.line.mood in ("sad", "reveal") else 0.05
        shots.append(Shot(start, end, kind, LENSES[kind], p.line.speaker, push))
    return _split_long(shots, fps)


def _split_long(shots: list[Shot], fps: int) -> list[Shot]:
    out: list[Shot] = []
    limit = int(MAX_SHOT_S * fps)
    for s in shots:
        length = s.end_frame - s.start_frame
        if length <= limit:
            out.append(s)
            continue
        n = math.ceil(length / limit)
        step = length // n
        for k in range(n):
            a = s.start_frame + k * step
            b = s.end_frame if k == n - 1 else a + step
            kind = s.kind if k % 2 == 0 else ("medium" if s.kind == "closeup" else "closeup")
            out.append(replace(s, start_frame=a, end_frame=b, kind=kind, lens=LENSES[kind]))
    return out


def mood_keys(placed: list[Placed], fps: int) -> list[tuple[int, str]]:
    keys: list[tuple[int, str]] = []
    for i, p in enumerate(placed):
        f = 0 if i == 0 else int(round((p.start - MOOD_LEAD_S) * fps))
        if not keys or keys[-1][1] != p.line.mood:
            keys.append((f, p.line.mood))
    return keys
```

```python
from __future__ import annotations

from .alignment import Word, words_from_chars
from .schema import Performance
from .timeline import Placed

SAFE_ZONES: dict[str, tuple[int, int]] = {  # (top, bottom) px kept clear by the platform UI
    "9:16": (220, 420), "16:9": (60, 60), "3:4": (80, 120), "1:1": (60, 60),
}
HOLD = 0.25
POP = r"{\fscx80\fscy80\t(0,80,\fscx108\fscy108)\t(80,160,\fscx100\fscy100)}"
PUNCH_POP = (r"{\fscx80\fscy80\t(0,100,\fscx130\fscy130)\t(100,200,\fscx118\fscy118)"
             r"\t(0,110,\frz-4)\t(110,220,\frz3)\t(220,320,\frz0)}")
PUNCH_HOLD = r"{\fscx118\fscy118}"


def ass_color(hex_rgb: str) -> str:
    h = hex_rgb.lstrip("#")
    r, g, b = int(h[0:2], 16), int(h[2:4], 16), int(h[4:6], 16)
    return f"&H00{b:02X}{g:02X}{r:02X}&"


def ts(seconds: float) -> str:
    cs = int(round(seconds * 100))
    h, cs = divmod(cs, 360000)
    m, cs = divmod(cs, 6000)
    s, cs = divmod(cs, 100)
    return f"{h}:{m:02d}:{s:02d}.{cs:02d}"


def group_words(words: list[Word], max_words: int = 4, gap: float = 0.3) -> list[list[Word]]:
    groups: list[list[Word]] = []
    cur: list[Word] = []
    for w in words:
        if cur and (len(cur) >= max_words or w.start - cur[-1].end > gap):
            groups.append(cur)
            cur = []
        cur.append(w)
        if w.text[-1] in ".!?,;:":
            groups.append(cur)
            cur = []
    if cur:
        groups.append(cur)
    return groups


def _ratio_for(width: int, height: int) -> str:
    r = width / height
    return min(SAFE_ZONES, key=lambda k: abs(eval_ratio(k) - r))


def eval_ratio(key: str) -> float:
    a, b = key.split(":")
    return int(a) / int(b)


def ass_header(width: int, height: int) -> str:
    fs = round(min(height * 0.042, width * 0.075))
    return (
        "[Script Info]\nScriptType: v4.00+\n"
        f"PlayResX: {width}\nPlayResY: {height}\nWrapStyle: 0\nScaledBorderAndShadow: yes\n\n"
        "[V4+ Styles]\n"
        "Format: Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, "
        "BackColour, Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, "
        "BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding\n"
        f"Style: Main,Segoe UI Black,{fs},&H00FFFFFF,&H00FFFFFF,&H00101010,&H96000000,"
        f"-1,0,0,0,100,100,0,0,1,{max(3, fs // 12)},{max(2, fs // 20)},8,60,60,0,1\n\n"
        "[Events]\nFormat: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text\n"
    )


def _clean(text: str) -> str:
    return text.replace("{", "(").replace("}", ")")


def build_ass(placed: list[Placed], perf: Performance, width: int, height: int) -> str:
    top, _ = SAFE_ZONES[_ratio_for(width, height)]
    x, y = width // 2, top + int(height * 0.04)
    lines = [ass_header(width, height)]
    all_groups: list[tuple[Placed, list[Word]]] = []
    for p in placed:
        words = [Word(w.text, p.start + w.start, p.start + w.end) for w in words_from_chars(p.voiced.chars)]
        all_groups += [(p, g) for g in group_words(words)]
    for gi, (p, group) in enumerate(all_groups):
        ch = perf.characters[p.line.speaker]
        base, hi = ass_color(ch.caption_color), ass_color(ch.highlight_color)
        next_start = all_groups[gi + 1][1][0].start if gi + 1 < len(all_groups) else None
        for k, w in enumerate(group):
            start = w.start
            end = group[k + 1].start if k + 1 < len(group) else w.end + HOLD
            if next_start is not None:
                end = min(end, next_start)
            body = " ".join(
                f"{{\\c{hi}}}{_clean(o.text)}{{\\c{base}}}" if j == k else _clean(o.text)
                for j, o in enumerate(group))
            if k == 0:
                fx = PUNCH_POP if p.line.punchline else POP
            else:
                fx = PUNCH_HOLD if p.line.punchline else ""
            lines.append(f"Dialogue: 0,{ts(start)},{ts(end)},Main,,0,0,0,,"
                         f"{{\\an8\\pos({x},{y})\\c{base}}}{fx}{body}")
    return "\n".join(lines) + "\n"
```

```python
from __future__ import annotations

import subprocess
from pathlib import Path

# Halation/bloom: isolate highlights, blur, tint warm, screen back over the image.
FILTER = (
    "[0:v]format=gbrp,split=2[base][hi];"
    "[hi]curves=all='0/0 0.72/0 1/1',gblur=sigma=30,"
    "colorchannelmixer=rr=1:gg=0.45:bb=0.25[halo];"
    "[base][halo]blend=all_mode=screen:all_opacity=0.45,"
    "eq=contrast=1.04:saturation=1.06,"
    "vignette=angle=PI/5,"
    "noise=alls=5:allf=t,"
    "ass=captions.ass,"
    "format=yuv420p[v];"
    "[1:a]loudnorm=I=-14:TP=-1.5:LRA=11,aresample=48000[a]"
)


def build_ffmpeg_cmd(fps: int, out_name: str) -> list[str]:
    return ["ffmpeg", "-y", "-loglevel", "error",
            "-framerate", str(fps), "-start_number", "1", "-i", "frames/%04d.png",
            "-i", "dialogue.wav",
            "-filter_complex", FILTER, "-map", "[v]", "-map", "[a]",
            "-c:v", "libx264", "-preset", "slow", "-crf", "16",
            "-c:a", "aac", "-b:a", "192k", "-movflags", "+faststart", "-shortest",
            out_name]


def finish(workdir: Path, fps: int, out_name: str) -> Path:
    # Relative paths + cwd avoid Windows drive-letter escaping inside the ass= filter.
    subprocess.run(build_ffmpeg_cmd(fps, out_name), cwd=workdir, check=True)
    return Path(workdir) / out_name
```

```python
def find_blender() -> str:
    env = os.environ.get("REELFORGE_BLENDER")
```

```python
    b = m.node_tree.nodes["Principled BSDF"]

    b.inputs["Roughness"].default_value = rough
    b.inputs["Metallic"].default_value = metal
    b.inputs["Subsurface Weight"].default_value = sss
    b.inputs["Subsurface Radius"].default_value = (1.0, 0.35, 0.2)
    b.inputs["Subsurface Scale"].default_value = 0.02
    b.inputs["Sheen Weight"].default_value = sheen
    b.inputs["Coat Weight"].default_value = coat
    if emit:
        b.inputs["Emission Color"].default_value = (*color, 1.0)
        b.inputs["Emission Strength"].default_value = emit
    return m


def code_screen_material(name, color, strength=3.0):
    """Emissive 'code lines' screen: Brick Texture rows read as lines of code. Node named 'Code'."""
    m = bpy.data.materials.new(name)
    m.use_nodes = True
    nt = m.node_tree
    nt.nodes.clear()
    out = nt.nodes.new("ShaderNodeOutputMaterial")
    em = nt.nodes.new("ShaderNodeEmission")
    br = nt.nodes.new("ShaderNodeTexBrick")
    br.name = "Code"
    br.inputs["Color1"].default_value = (*color, 1.0)
    br.inputs["Color2"].default_value = (color[0] * 0.5, color[1] * 0.5, color[2] * 0.5, 1.0)
    br.inputs["Mortar"].default_value = (0.01, 0.012, 0.02, 1.0)
    br.inputs["Scale"].default_value = 6.0
    br.inputs["Mortar Size"].default_value = 0.03
    br.inputs["Brick Width"].default_value = 0.35
    br.inputs["Row Height"].default_value = 0.08
    em.inputs["Strength"].default_value = strength
    nt.links.new(br.outputs["Color"], em.inputs["Color"])
    nt.links.new(em.outputs["Emission"], out.inputs["Surface"])
    return m


def _finish(name, bm, coll, mat=None, smooth=True):
    me = bpy.data.meshes.new(name)
    bm.to_mesh(me)
    bm.free()
    if smooth:
        for p in me.polygons:
            p.use_smooth = True
    if mat:
        me.materials.append(mat)
    o = bpy.data.objects.new(name, me)
    coll.objects.link(o)
    return o


def box(name, center, size, coll, mat=None):
    bm = bmesh.new()
    bmesh.ops.create_cube(bm, size=1.0)
    bmesh.ops.scale(bm, vec=Vector(size), verts=bm.verts)
    bmesh.ops.translate(bm, vec=Vector(center), verts=bm.verts)
    return _finish(name, bm, coll, mat, smooth=False)


def ellipsoid(name, center, radii, coll, mat=None, segs=32, subd=1):
    """Unit sphere mesh; position/size live on the object so drivers can scale it."""
    bm = bmesh.new()
    bmesh.ops.create_uvsphere(bm, u_segments=segs, v_segments=segs // 2, radius=1.0)
    o = _finish(name, bm, coll, mat)
    o.location = center
    o.scale = radii
    if subd:
        mod = o.modifiers.new("Subd", "SUBSURF")
        mod.levels = mod.render_levels = subd
    return o


def empty(name, loc, coll, parent=None):
    o = bpy.data.objects.new(name, None)
    o.empty_display_type = "PLAIN_AXES"
    o.location = loc
    coll.objects.link(o)
    if parent is not None:
        o.parent = parent
    return o


def look_at(obj, target):
    direction = Vector(target) - obj.location
    obj.rotation_euler = direction.to_track_quat("-Z", "Y").to_euler()
```

```python
    return [(cx, cz)] + ring
```

```python
from bl_common import look_at  # noqa: E402
```

```python
SHOT = {"wide": (2.4, 2.8, math.radians(-15), math.radians(6)),
        "medium": (1.5, 2.0, math.radians(12), math.radians(4)),
        "closeup": (1.0, 1.6, math.radians(-6), math.radians(2))}

    print("WARNING: M1 renders only the first character")

    dst.collections = [c for c in src.collections if c == "CHAR_base"]
coll = dst.collections[0]
sc.collection.children.link(coll)
objs = {o.name.split(".")[0]: o for o in coll.objects}
root, head, ctrl = objs["CHAR_root"], objs["Head"], objs["FaceCtrl"]
root.location = bpy.data.objects[char["mark"]].location
bpy.context.view_layer.update()

def key_track(obj, path, values, eps=0.002, index=-1):
    last = None
    for f, v in enumerate(values):
        if last is None or abs(v - last) > eps or f == len(values) - 1:
            if index >= 0:
                getattr(obj, path)[index] = v
                obj.keyframe_insert(path, index=index, frame=f + 1)
            else:
                obj[path[2:-2]] = v
                obj.keyframe_insert(path, frame=f + 1)
            last = v

    if ch == "headNod" or ch not in ctrl.keys() or max(values) == 0.0:

        ld = bpy.data.objects[name].data
        ld.color, ld.energy = p[ck], p[wk]

        ld.keyframe_insert("energy", frame=frame)

        node.inputs["Color1"].default_value = (*c, 1.0)
        node.inputs["Color2"].default_value = (c[0] * 0.5, c[1] * 0.5, c[2] * 0.5, 1.0)

        node.inputs["Color2"].keyframe_insert("default_value", frame=frame)

    apply_mood(presets[m], f + 1 + 5)

    dirv = Vector((math.sin(az), -math.cos(az), math.sin(el))).normalized()
    a, b = s["start_frame"] + 1, s["end_frame"]
    for f in list(range(a, b + 1, 2)) + [b]:
        u = (f - a) / max(1, b - a)
        d = dist * (1 - s["push"] * u)
        jitter = Vector((math.sin(f * 0.21) + 0.5 * math.sin(f * 0.53 + 1.0), 0.0,
                         math.sin(f * 0.17 + 2.0) + 0.5 * math.sin(f * 0.41))) * 0.003 * dist
        cam.location = aim + dirv * d + jitter
        look_at(cam, aim)
        cam.keyframe_insert("location", frame=f)
        cam.keyframe_insert("rotation_euler", frame=f)
    marker = sc.timeline_markers.new(f"S{i}", frame=a)
    marker.camera = cam

sc.eevee.taa_render_samples = plan["samples"]

sc.render.fps = fps
sc.frame_start, sc.frame_end = 1, n
sc.render.image_settings.file_format = "PNG"
sc.render.image_settings.color_depth = "8"
sc.camera = cams[0][0]

        sc.frame_set((a + b) // 2)
        sc.render.filepath = str(Path(plan["out_stills"]) / f"shot_{i:02d}.png")
        bpy.ops.render.render(write_still=True)
```

```python
def build_parser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(prog="reelforge")
    sub = p.add_subparsers(dest="cmd", required=True)
    sub.add_parser("build-assets", help="build base character + environments")
    r = sub.add_parser("run", help="render a project folder containing performance.json")
    r.add_argument("project", type=Path)
    r.add_argument("--stage", choices=["stills", "full"], default="full")

    key = os.environ.get("ELEVENLABS_API_KEY")
    if not key:
        raise SystemExit("Set ELEVENLABS_API_KEY before running.")
    project = project.resolve()
    perf = load_performance(project / "performance.json")
    out = project / "out"
    out.mkdir(parents=True, exist_ok=True)

    voiced = {l.id: synthesize_line(l, perf.characters[l.speaker].voice_id, out / "audio", key)
              for l in perf.lines}

    placed, total = place_lines(perf.lines, voiced, durations)
    n_frames = math.ceil(total * perf.fps)
```

```python
from __future__ import annotations

from .arkit import ARKIT_NAMES

_VALID = set(ARKIT_NAMES)


def frames_to_tracks(frames: list[dict], fps: int, n_frames: int) -> dict[str, list[float]]:
    frames = sorted(frames, key=lambda f: f["time"])
    names = sorted({k for f in frames for k in f["blendshapes"] if k in _VALID})
    tracks = {n: [0.0] * n_frames for n in names}
    if not frames:
        return tracks
    j = 0
    for i in range(n_frames):
        t = i / fps
        while j + 1 < len(frames) and frames[j + 1]["time"] <= t:
            j += 1
        a = frames[j]
        b = frames[j + 1] if j + 1 < len(frames) and t >= a["time"] else a
        span = b["time"] - a["time"]
        u = 0.0 if span <= 0 else min(1.0, max(0.0, (t - a["time"]) / span))
        for n in names:
            v = a["blendshapes"].get(n, 0.0) * (1 - u) + b["blendshapes"].get(n, 0.0) * u
            tracks[n][i] = min(1.0, max(0.0, v))
    return tracks
```
